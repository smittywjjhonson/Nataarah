# NATA ARAH Website

Landing page statis NATA ARAH — Business · Strategy · Creative, dibuat dengan HTML, CSS, dan JavaScript tanpa framework.

## Menjalankan

Buka `index.html` di browser, atau gunakan server lokal pilihan selama pengembangan.

## Halaman

- `index.html` — halaman utama
- `core-service.html` — layanan Core Service
- `enabler-service.html` — layanan Enabler Service
- `pricing.html` — paket kemitraan
- `reports.html` — contoh laporan
- `contact.html` — halaman kontak

## Identitas merek

- `assets/images/nataarah-primary-logo.png` — logo utama
- `assets/images/nataarah-icon.png` — ikon merek untuk navigasi
- `assets/icons/nataarah-icon.png` — favicon dan ikon layar utama
- Warna merek: Deep Green `#123B32`, Horizon Sage `#8C9870`, Horizon Gold `#C4A06A`, Warm Sand `#F3EFE6`, dan Deep Charcoal `#202828`

Dokumen dan master aset merek berada di folder `NATAARAH Aset Logo`.
