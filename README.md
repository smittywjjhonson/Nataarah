# INSIDER

Kerangka landing page statis menggunakan HTML, CSS, dan JavaScript tanpa dependensi tambahan.

## Menjalankan

Buka `index.html` di browser. Untuk pengembangan, gunakan ekstensi server lokal pilihanmu agar perubahan lebih mudah dilihat.

## Struktur

- `index.html` — struktur dan konten halaman
- `css/style.css` — gaya dan tata letak responsif
- `js/main.js` — navigasi mobile dan tahun footer
- `assets/images/` — tempat menyimpan gambar
- `assets/icons/` — ikon dan favicon

Konten di `index.html` saat ini adalah contoh sementara bertema media editorial. Ganti teks, warna, tipografi, dan gambar setelah arah final INSIDER ditentukan.
